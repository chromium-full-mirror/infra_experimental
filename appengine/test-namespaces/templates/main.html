Testing Namespaces

This app is a test lab for evaluating Datastore namespaces as a secure separation of internal and external data. The idea is to see how easy it is to keep the internal data secure, and if it is easy to make programmatic mistakes resulting in data leaks (hint: it should be hard, and not possible with the obvious default behavior).

For the purposes of this app:

  • Only users at *@google.com can access and modify internal data,
  • any authenticated user can modify public data,
  • anyone can read public data.
